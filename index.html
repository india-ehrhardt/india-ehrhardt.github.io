An end-to-end sales forecasting project built on the Rossmann Store Sales dataset (1,115 stores), covering the full pipeline from messy raw data to a tool a store manager could actually open.

  • Cleaned and explored historical daily sales data, digging into promo, holiday, and seasonality effects store by store
  • Engineered time-based and categorical features to feed the model
  • Trained and tuned a LightGBM model for daily sales prediction, using AI-assisted workflows to speed up iteration and validating results against baseline models
  • Deployed the finished model as an interactive Streamlit dashboard so results are explorable, not just plotted in a notebook
